# Rúbrica de calificación (documento para el docente)

Cada subcriterio se verifica leyendo el XML interno del .docx (estilos efectivos, listas, secciones, formas, notas, comentarios, propiedades). Los puntos se reparten **por dificultad**: Básico = 1, Intermedio = 2, Avanzado = 3 (peso relativo), ajustados para sumar exactamente el total del reto.

Se acepta cualquier forma válida de lograr el resultado (por ejemplo, formato directo o modificación del estilo, color azul de cualquier paleta, resaltado o sombreado gris, tema o color explícito). Los criterios que dependen de otro (p. ej. «solo esos tres párrafos») solo puntúan si se cumple lo fundamental.

## Notas de uso
- Las soluciones oficiales (`docente/soluciones`) **no deben publicarse** junto con el sitio.
- El nombre del estudiante se verifica contra el que escribió al iniciar (portada, comentario o propiedad según el reto).
- El tiempo trabajado se guarda en las propiedades personalizadas del archivo de entrega (`TBox_TiempoTrabajado`) y se muestra en el tablero.
- Limitación: el evaluador verifica el resultado en el archivo; no puede saber qué comandos usó el estudiante ni verificar «Copiar formato» como herramienta.
